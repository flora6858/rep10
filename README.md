# GitHub User Finder

**Автор:** [Грачев Семен]

## Описание

Приложение «GitHub User Finder» — это GUI‑инструмент для поиска пользователей GitHub с возможностью добавления избранных пользователей в локальное хранилище.

### Основные функции:
* Поиск пользователей GitHub через официальный API.
* Отображение результатов в виде таблицы (логин, имя, количество публичных репозиториев).
* Добавление пользователей в избранное.
* Сохранение избранного
